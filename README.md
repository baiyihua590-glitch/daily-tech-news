# 每日 AI & 科技新闻简报

每天中午 12:00 自动推送 AI & 科技新闻到飞书。

## 配置步骤

### 1. 创建飞书群机器人

1. 打开飞书 → 创建群聊（只拉自己或随便拉个人）
2. 群设置 → 群机器人 → 添加机器人 → 自定义机器人
3. 取名「星期六简报」，复制 Webhook 地址

### 2. 配置 GitHub

1. 创建 GitHub 仓库，将本项目代码推送上去
2. 在仓库 Settings → Secrets and variables → Actions 添加：
   - `FEISHU_WEBHOOK` = 你复制的飞书 Webhook 地址

### 3. 完工

每天北京时间 12:00 自动执行，你也可以在 Actions 页面手动触发测试。
